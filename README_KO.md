# 작은 모델용 도구 없는 하네스

폐쇄망에서 작은 언어 모델에게 표·문서가 붙은 업무 질문을 시킬 때 쓰는 하네스다. 모델이 자료를 눈으로 읽고 암산하는 대신, 파이썬 코드로 읽고 계산하게 만든다. 표준 라이브러리만 쓴다.

## 한 문단 요약

요청을 먼저 판단한다. 답 형식이 정해졌거나 표·숫자·코드가 필요하면 하네스를 쓰고, 자유 글쓰기는 모델이 바로 답한다. 하네스에서 모델에게 주는 행동은 `run_python` 하나다.

- **하네스가 미리 하는 일:** 질문에 붙은 표를 정리된 CSV 파일(`table_1.csv` …)로 잘라 두고, 질문 전체를 `input.txt`로 저장한다.
- **모델이 하는 일:** 그 파일을 읽는 코드를 써서 답을 계산한다.
- **하네스의 기계적 검사:**
  - 코드 없이 낸 숫자 답은 한 번 되돌린다.
  - 답 형식을 검사한다.
  - 같은 실패가 반복되면 안내한다.
  - 호출 예산을 센다.
- **끝내기:** 코드 출력의 마지막 줄이 요청한 답 형식이면 그대로 답으로 쓴다.

Qwen3.5-9B에서 결과는 다음과 같다.

- **직접 만든 업무 과제:** 그냥 답하기 3~13%가 80% 안팎이 됐다.
- **처음 보는 공개 문항(TAT-QA·GSM-Hard):** 그냥 답하기 24% → 하네스 85%. 같은 모델의 사고 모드와 정확도는 같은 수준(−2%p, 95% CI −7 ~ +3, 사고 모드 일부 실행 중)이고, 출력 토큰은 1/4, 시간은 절반 이하다.
- **범용성:** 자유 글쓰기(IFEval)는 하네스를 거치지 않게 판단해 손해가 없고(+4%p), 말로 된 추론(BBH)은 +27%p(중간 결과)다.

## 써 보기

```powershell
cd bench
$env:LLM_URL = "https://<게이트웨이>/v1/chat/completions"
$env:LLM_MODEL = "<모델 이름>"
uv run --offline --no-project --python 3.12 ask.py question.txt                       # 글로 답
uv run --offline --no-project --python 3.12 ask.py question.txt --json "total:int"    # JSON 한 줄로 답
```

- `question.txt`에는 질문과 붙여 넣은 자료(표, 문서)를 함께 쓴다.
- **API 키:** 환경변수 `LLM_API_KEY`가 없으면 실행할 때 물어본다. 사내 인증서는 `LLM_CA_FILE`로 지정한다.
- **실행 기록:** `runs/ask/<시각>/trace.json`에 남는다.
- **주의:** 모델이 쓴 코드가 이 PC에서 실행된다.
  - 실행마다 새 폴더를 쓰고, 환경변수를 넘기지 않고(키가 보이지 않음), 시간 상한을 둔다.
  - 다만 보안 격리 장치는 아니므로 중요한 파일이 있는 폴더에서는 돌리지 않는다.

## 구성

| 파일 | 역할 |
|---|---|
| `bench/hx.py` | 하네스 본체. 모델 호출(재시도, 출력 상한 자동 상향), 대화 루프, 검사, 바로 끝내기, 실행 기록과 이어 하기 |
| `bench/env.py` | `run_python` 실행기(격리 모드, 자료 크기에 맞춘 시간 상한, 출력 자르기), 표 추출과 정규화 |
| `bench/skills/python_v3.md` | 모델에게 주는 짧은 작업 규칙 7줄 |
| `bench/ask.py` | 질문 하나를 하네스로 실행 |
| `bench/ab.py` | 조건별 비교 시험 실행과 통계(문항별 짝 비교, 부트스트랩 신뢰구간, 부호 검정) |

## 시험 체계

하네스보다 오래 쓸 자산이다. 새 모델이 들어오면 같은 과제로 "그냥 답하기 / 사고 모드 / 하네스"를 돌려 하네스를 켤지 판정한다.

| 파일 | 내용 |
|---|---|
| `bench/tasks_notool.py`, `tasks_notool2.py` | 자료를 붙인 한국어 업무 과제 30개씩. 작성자는 하네스 코드를 보지 못했다 |
| `bench/tasks_messy.py` | 지저분한 실제형 자료 24개(2줄 머리글, 소계 행, 한글 금액, 병합 셀, 마크다운 표 등 8유형) |
| `bench/tasks_bench.py` | 공개 벤치마크 TAT-QA, GSM-Hard 연결(데이터와 공식 채점 코드는 `bench/ext/`, 커밋하지 않음) |
| `bench/PREREG_KO.md` | 사전 등록. 결과를 보기 전에 조건과 판정 기준을 커밋하고, 실행 중 조정과 결과를 기록 |
| `bench/BENCH_PLAN_KO.md` | 공개 벤치마크 계획 |
| `bench/gsmhard_label_*` | GSM-Hard 정답 오류 감사(표본의 약 30%가 정답 오류) |

## 보류한 것

업무 도구(ERP 조회, 문서 읽기, 코드 수정)를 주는 과제에서는 하네스 검사가 효과가 없어 보류했다. 사내 GLM에서 하네스 켬 대 끔은 +1.1%p였고, Qwen에서도 효과가 없었다. 관련 파일은 `bench/tasks.py`, `tasks_gen.py`, `bfcl_ab.py`이다. 모델·게이트웨이 탐침 `probe.py`, `behavior.py`는 새 모델의 프로필을 잴 때 계속 쓴다.
